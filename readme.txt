This repository has a workflow in R for analysis of bulk RNAseq from Guan and Petersen, 2026.

Source data is located in "RNAseqData" folder and was downloaded from Planmine (https://planmine.mpinat.mpg.de/planmine/begin.do) using the QueryBuilder function to identify the dataset “Time Series Analysis Result” and exported as log2FC-expression values normalized to 0-hour conditions for each dataset of head regeneration, tail regeneration, and incision timecourses, collected from the same tissue region near each wound site. The dataset uses wound sites generated in the anterior portion of the animal.

The "Annotation" folder contains annotation information necessary for the code to execute.  These are referenced with hard-coded directory inputs that the user needs to modify for the code to run.  The files contain unique gene identifiers for subsets of genes analyzed by the two analyses, along with corresponding gene names.   

The folder "Analysis_Timecourse_RNAseq_101426" contains code in R to analyze the time courses for significantly up and down regulated genes.  Analysis to detect genes activated by injury was conducted in R by fitting the timecourse data to cubic splines with 4 degrees of freedom using limma, followed by false-discovery-adjusted F-tests comparing the fit parameter values to the null hypothesis of a flat trajectory and assessment of the peak maximum log2FC > 0. This code determines the fraction of previously described planarian wound-induced genes measured as significantly upregulated in this dataset and displayed as a Venn diagram. 

The folder "Analysis_RNAseq_Heatmaps_Impulse_MaxDiff_101426" contains code in R to generate heatmaps of gene expression, scatterplots of expression over time for sets of genes, bar plots and histograms displaying differences in maximum activation between responses to regeneration versus recovery after incision, modeling of gene expression activation using impulse functions, and plots of fitted impulse function parameters across experimental conditions. Impulse fitting used a 4-parameter impulse function (A * sigmoid(B * (x - t1)) * (1 - sigmoid(B * (x - t2))) with non-linear least-squares using the Levenberg-Marquardt algorithm implemented in nlsm() from the minpack.lm package in R.

The code is written to read the input data files and the input annotation files from working directories that the user must specify when the dataset and analysis is downloaded on their own machine. The working directory specified by the user also serves as the output directory for plots and tables.
